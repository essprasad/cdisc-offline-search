Privacy Policy

CDISC Offline Search

Effective date: 1 October 2026

This Privacy Policy explains how CDISC Offline Search handles information when you use the application.

1. Information the app collects

CDISC Offline Search is designed to work offline using reference data packaged with the application. The app does not ask you to create an account and does not collect, store, or transmit personal information, patient information, search queries, or the content you view or export.

2. Local data and exported files

Searches and filtering are performed on data available locally in the application. When you export results to Excel, the file is created on your device or downloaded through your browser. The app does not send exported files or search results to the developer.

3. Internet access and hosting

The web version is hosted using GitHub Pages. Opening the web version requires an internet connection to access the hosted application and its resources. GitHub may process technical information, such as request logs, under its own policies. After the application and required resources are available locally or cached by your browser, supported features are designed to operate offline.

4. Third-party services

The app does not include advertising, in-app analytics, or third-party account sign-in as part of its intended functionality. The web version relies on GitHub Pages for hosting, and use of that service is subject to GitHub's policies.

5. Children's privacy

The app is a general-purpose reference tool and is not designed to collect personal information from children or any other users.

6. Data security and retention

Because the app does not collect or transmit user search activity or personal information, the developer does not maintain a user profile or a server-side history of searches. Files exported by the user are managed by the user and their device.

7. Changes to this policy

This policy may be updated if the app's functionality or data practices change. The latest version will be published at this URL, with the effective date updated accordingly.

8. Contact

For questions about this Privacy Policy, contact the developer through the developer's GitHub profile.

9. CDISC reference content

CDISC Offline Search is an independent reference application. It is not an official CDISC product and is not endorsed, certified, maintained, or supported by CDISC. CDISC standards, terminology, and related materials remain subject to their respective ownership and usage terms.
